# 🏆 Sistema VIP de Apuestas Deportivas

[![Python Version](https://img.shields.io/badge/python-3.8+-blue.svg)](https://python.org)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)

> Sistema profesional de escaneo de apuestas deportivas con valor real. 
> Escanea más de 30 ligas mundiales y envía picks con EV positivo directamente a Telegram.

## 📊 **Características Principales**

- 🌍 **Cobertura Global**: Más de 30 ligas de todo el mundo
- 🎯 **Picks con Valor**: Solo picks con Valor Esperado (EV) positivo
- 📈 **30 Picks Diarios**: Envío automático de 30 picks por día
- 🛡️ **Anti-Duplicados**: Sistema inteligente que evita repeticiones
- ⚡ **Rendimiento**: Escaneo optimizado y paralelizado
- 📱 **Telegram**: Integración completa con bot de Telegram
- 💾 **Persistencia**: Base de datos SQLite para histórico
